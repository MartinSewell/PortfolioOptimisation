Portfolio Optimisation

A free macro-enabled Excel spreadsheet that performs portfolio optimisation/allocation using 14 methods.  No Excel add-ins, plugins, Solver, Python or external software required.

The spreadsheet includes the following methods:
• Equal Weight
• Market-Cap / Benchmark
• Fundamental Tilt
• Inverse Volatility
• Minimum Variance
• Maximum Sharpe
• Maximum Sortino
• Maximum Return
• Minimum CVaR
• Risk Parity
• Maximum Diversification
• Target Return / Min Vol
• Minimum Drawdown
• HRP Approximation

Download and use:
1. Download PortfolioOptimiser.xlsm.
2. Save the file locally.
3. (Windows) In Windows File Explorer, right-click the file.
4. (Windows) Click Properties.
5. (Windows) On the General tab, tick Unblock if the checkbox appears.
6. (Windows) Click Apply, then OK.
7. Open the file in desktop Microsoft Excel, not Excel Online.
8. If Excel shows a yellow security bar, click Enable Content.
9. Go to the Inputs sheet.
10. Set Periods per Year to match your data (252 daily, 52 weekly, 12 monthly).
11. Paste arithmetic period returns from row 28 downwards.
12. Click RUN OPTIMISER.
