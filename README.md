An Excel spreadsheet (no add-ins, plugins or external software required) that performs portfolio optimisation using 14 methods:
• Equal Weight
• Market-Cap / Benchmark
• Fundamental Tilt
• Inverse Volatility
• Minimum Variance
• Maximum Sharpe
• Maximum Sortino
• Maximum Return
• Minimum CVaR
• Risk Parity
• Maximum Diversification
• Target Return / Min Vol
• Minimum Drawdown
• HRP Approximation

1. Download PortfolioOptimiser.xlsm.
2. Save it locally.
3. In Windows File Explorer, right-click the file.
4. Click Properties.
5. On the General tab, tick Unblock if the checkbox appears.
6. Click Apply, then OK.
7. Open the file in desktop Excel (not Excel Online).
8. If Excel shows a yellow security bar, click Enable Content.
9. Go to the Inputs sheet.
10. Paste arithmetic period returns from row 28 downwards.
11. Click 'RUN OPTIMISER'.
